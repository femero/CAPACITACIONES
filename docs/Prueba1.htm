Java 21 (Eclipse Temurin) Base JDK para compilar y ejecutar ▾
  • Descarga Java 21 (LTS) · Windows · x64 · JDK · MSI desde Eclipse Temurin.
  • En Custom Setup activa Add to PATH y Set JAVA_HOME variable.
  • Verifica que JAVA_HOME apunte a la carpeta del JDK (sin \bin).
java -version
javac -version
echo "$JAVA_HOME"

Esperado: Java y javac muestran 21; JAVA_HOME muestra la carpeta del JDK 21, sin bin al final.

2✓
Apache Maven 3.9.x Base Gestión de dependencias y build ▾
  • Descarga el Binary zip archive de Maven 3.9.x.
  • Extrae en C:\Tools → te quedará C:\Tools\apache-maven-3.9.x.
  • Abre Inicio → Editar las variables de entorno del sistema → Variables de entorno → Path → Editar → Nuevo y agrega la ruta de la carpeta bin. Conserva las demás entradas.
C:\Tools\apache-maven-3.9.16\bin

Importante: 3.9.16 es un ejemplo. Usa el nombre real de la carpeta que descargaste.

mvn -v

Esperado: Maven 3.9.x y Java version: 21.

Prueba de funcionamiento

Validaremos Java 21, Maven, Core Tools y una escritura real en Azurite. No se crean recursos ni se despliega nada en Azure.

1. Crear el proyecto

Mantén Azurite abierto. En otra Git Bash, copia este bloque completo. La primera descarga puede tardar unos minutos. Si ya existe fase0-prueba, reutilízalo y pasa al punto 2.

mkdir -p "$HOME/azure-taller"
cd "$HOME/azure-taller"
mvn archetype:generate \
  -DarchetypeGroupId=com.microsoft.azure \
  -DarchetypeArtifactId=azure-functions-archetype \
  -DarchetypeVersion=1.66 \
  -DgroupId=com.taller \
  -DartifactId=fase0-prueba \
  -Dversion=1.0-SNAPSHOT \
  -Dpackage=com.taller \
  -DappName=fase0-prueba \
  -DappRegion=westus \
  -DjavaVersion=21 \
  -DinteractiveMode=false

Esperado: BUILD SUCCESS y una carpeta llamada fase0-prueba. Abre esa carpeta desde File → Open en IntelliJ y confirma el SDK y Maven del paso 4.

2. Configurar y compilar

Este bloque crea la configuración local y una función HTTP que escribe un mensaje en la cola fase0-prueba. Úsalo únicamente en el proyecto de prueba: reemplaza su local.settings.json y SmokeProbe.java.

cd "$HOME/azure-taller/fase0-prueba"
cat > local.settings.json <<'JSON'
{
  "IsEncrypted": false,
  "Values": {
    "FUNCTIONS_WORKER_RUNTIME": "java",
    "AzureWebJobsStorage": "UseDevelopmentStorage=true"
  }
}
JSON
cat > src/main/java/com/taller/SmokeProbe.java <<'JAVA'
package com.taller;

import com.microsoft.azure.functions.*;
import com.microsoft.azure.functions.annotation.*;
import java.util.Optional;

public class SmokeProbe {
    @FunctionName("SmokeProbe")
    public HttpResponseMessage run(
        @HttpTrigger(name = "req", methods = {HttpMethod.GET},
            authLevel = AuthorizationLevel.ANONYMOUS)
        HttpRequestMessage<Optional<String>> request,
        @QueueOutput(name = "message", queueName = "fase0-prueba",
            connection = "AzureWebJobsStorage") OutputBinding<String> message,
        final ExecutionContext context) {
        String result = "Ambiente OK - Java " + System.getProperty("java.version");
        message.setValue(result);
        return request.createResponseBuilder(HttpStatus.OK).body(result).build();
    }
}
JAVA
mvn clean package

Esperado: BUILD SUCCESS. No subas local.settings.json con secretos al repositorio; conserva su exclusión en .gitignore.

3. Ejecutar la función

cd "$HOME/azure-taller/fase0-prueba"
mvn azure-functions:run

Esperado: aparece la función SmokeProbe en http://localhost:7071/api/SmokeProbe. Deja esta ventana abierta, además de la ventana de Azurite.

4. Probar con Postman

  • Con Functions y Azurite activos, abre Postman y crea una solicitud HTTP nueva mediante New → HTTP o una pestaña nueva de solicitud.
  • Selecciona el método GET y pega http://localhost:7071/api/SmokeProbe.
  • En Authorization, selecciona No Auth. No necesitas body para esta solicitud.
  • Pulsa Send.

Esperado: estado 200 OK y cuerpo Ambiente OK - Java 21.... En Azurite debe aparecer una operación POST a fase0-prueba/messages con estado 201.

Alternativa: verificar desde Git Bash

Abre una tercera ventana de Git Bash y ejecuta:

curl -i http://localhost:7071/api/SmokeProbe

Esperado: HTTP 200 y Ambiente OK - Java 21.... En la ventana de Azurite debe aparecer una operación POST a la cola fase0-prueba/messages con estado 201: confirma que el mensaje se guardó.

✓
Ambiente habilitado: compilación correcta, respuesta en Postman con Java 21 y mensaje escrito en Azurite. Ahora sí marca la verificación final como completada. Al terminar, detén Functions y Azurite con Ctrl+C en sus respectivas ventanas.

Proyecto basado en el arquetipo oficial, versión 1.66. No necesitas iniciar sesión en Azure para esta prueba local.
